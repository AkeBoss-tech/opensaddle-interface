Inventory 03

Visual language

The system uses quiet neutral surfaces, restrained semantic color, compact controls, and explicit status labeling. Evidence and approval states must never rely on color alone.

Spacing scale

4, 8, 12, 16, 20, 24, and 32px. Dense controls use 8–12px internal spacing; page sections use 24–48px.

Shape and depth

6px small, 9px medium, 14px large, and full-pill radii. Borders carry most hierarchy; shadows are reserved for menus, dialogs, and detached overlays.

Typography

Inter / system sans for interface copy. SFMono/Consolas for routes, hashes, commands, and evidence identifiers.

Status vocabulary

Every state pairs tone with a readable label and, where relevant, an icon or pulse.

Iconography

Line icons at 15, 18, 22, and 30px. Lucide is the default vocabulary; Phosphor, Tabler, and Heroicons are available through Icon Lab.

Motion and focus

120ms fast and 200ms normal transitions, using a soft ease-out. Reduced-motion disables nonessential animation. Focus uses a two-layer accent ring.
