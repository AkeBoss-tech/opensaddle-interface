04 · OpenSaddle direction

Prefer task-first, borrow inspection depth

Recommendation

Codex shell, Cursor moments.

Keep a quiet thread-first shell for outcomes, authority, and evidence. Borrow Cursor’s spatial depth when the user enters a concrete inspection mode: compare runs, review a diff, inspect provenance, or annotate a UI.

Keep persistentTasks, status, blockers, approvals, and next action.
Reveal contextuallyDiffs, terminal, browser, artifact editor, evidence, and logs.
AvoidA permanent file tree, agent roster, project navigator, and controls competing in the left rail.
