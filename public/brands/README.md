# Integration marks

Marks identify the named product; they do not imply endorsement, installation,
or equal capability. Display them with the product name and capability label.
They are bundled locally: loading the public landing page does not contact a
logo CDN or provider.

- `cursor.svg`: unchanged `General Logos/Cube/SVG/CUBE_2D_LIGHT.svg` from
  https://cursor.com/brand and its linked official brand archive:
  https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/brand/cursor-brand-assets.zip
- `openai.svg`: existing OpenSaddle Interface `ProviderLogo.tsx` OpenAI path,
  reused without geometry changes. Brand reference: https://openai.com/brand/
- Claude, Gemini, GitHub, Docker, Tailscale, MCP, and Linux: unmodified monochrome
  SVGs from Simple Icons 16.32.0 (`https://cdn.jsdelivr.net/npm/simple-icons@16.32.0/icons/<slug>.svg`).
  These are community-maintained brand vectors, not an assertion of vendor approval.
  Collection: https://github.com/simple-icons/simple-icons/tree/16.32.0
  The collection's CC0 license is included in `SIMPLE-ICONS-LICENSE.txt`;
  brand trademarks remain owned by their respective holders.
- OpenSaddle's existing `../opensaddle-mark-transparent.svg` is reused throughout.

Platform names for macOS and Windows use generic device icons. Windows remains
explicitly qualification-pending. This page does not invent certified platform
badges or portray the planned cloud service as available.

Retrieved September 20, 2026. The live Core registry and readiness checks, not
this static overview, determine what a connected workspace can execute.
